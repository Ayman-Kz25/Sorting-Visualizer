# Sorting Visualizer 📊

A simple browser-based Sorting Visualizer built with HTML, CSS, and JavaScript. This project demonstrates how the **Bubble Sort** algorithm works through an interactive bar visualization.

## Features 

* Generate a random array
* Choose array length from 2 to 15
* Visualize Bubble Sort step by step
* Highlight elements being compared
* Highlight elements being swapped
* Show sorted elements
* Display the values currently being compared
* Track sorting steps
* Reset the visualization at any time
* Colorful pastel bar design
* Responsive layout

## How It Works

The visualizer uses **Bubble Sort** to sort the generated array.

Each step compares two neighboring values. If they are in the wrong order, they are swapped. The bars are animated during the process so you can follow how the array gradually becomes sorted.

## Technologies

* HTML
* CSS
* JavaScript
* DOM Manipulation

## Getting Started

Clone the repository or download the project files.

Open `index.html` in your browser and:

1. Select the desired array length.
2. Click **Generate Array**.
3. Click **Sort Array**.
4. Watch Bubble Sort visualize the sorting process.
